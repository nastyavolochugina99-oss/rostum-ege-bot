# Бот записи на тьюторские сессии (Ростум ЕГЭ)

Ученики выбирают **только время** сессии (раз в 2 недели, 30 минут). Тьютор не выбирается — назначается внутренне по слотам.

## Что нужно от тебя для запуска

1. **Токен бота**  
   Создай бота в Telegram через [@BotFather](https://t.me/BotFather), получи токен. Положи его в файл `.env` в папке бота:
   ```bash
   BOT_TOKEN=123456:ABC-DEF...
   ```
   Файл `.env` не коммитится в репозиторий (уже в `.gitignore`).

2. **Слоты тьюторов**  
   Слоты задаются в файле `data/slots.json`. Сейчас там пример: вторник/среда 17:00 и 18:30, по 6 мест на слот (итого до 24, можно поменять под 12 человек).  
   Формат одного слота:
   ```json
   {
     "id": "tue_17",
     "day": "вторник",
     "time": "17:00",
     "capacity": 6
   }
   ```
   - `id` — уникальный ключ (латиница, без пробелов).  
   - `day` — день недели по-русски (понедельник, вторник, …).  
   - `time` — время начала в формате `HH:MM`.  
   - `capacity` — сколько учеников можно записать на этот слот.

   Подставь реальные окна двух тьюторов и нужные `capacity` (например, по 6 на тьютора = 12 мест всего, или как договоритесь).

3. **Тексты**  
   Приветствие и кнопки заданы в `bot.py` в словаре `TEXTS`. При желании можно поменять формулировки под свой тон.

## Как запустить

```bash
cd "tutor-booking-bot"
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Отредактируй .env — вставь BOT_TOKEN
python bot.py
```

Бот будет работать, пока процесс не остановить (Ctrl+C). Для постоянной работы нужен сервер или хостинг — **детальный пошаговый план публикации** см. в [DEPLOY.md](DEPLOY.md).

## Как это видит ученик

1. Нажимает **Старт** (/start) — видит приветствие и кнопки: **«Выбрать время сессии»**, **«Написать куратору»**.  
2. Нажимает «Выбрать время» — открывается список слотов по 6 на страницу, внизу **«← Пред.»** / **«След. →»** (если страниц несколько) и **«← В меню»**.  
3. Выбирает слот — получает подтверждение и кнопку **«← В меню»** (возврат без повторного /start).  
4. В меню после записи показывается текст «Ты уже записан на …» и только кнопка **«Написать куратору»**. Время поменять нельзя — только через куратора.

Записи хранятся в `data/bookings.db` (создаётся автоматически). Один пользователь = один слот.

## Как менять слоты

Редактируй `data/slots.json`: добавь или удали объекты, измени `day`, `time`, `capacity`. Перезапусти бота, чтобы подхватить изменения. Уже сделанные записи привязаны к `id` слота: если удалить слот или поменять `id`, старые записи по этому `id` останутся в БД (можно потом почистить вручную или добавить админ-команду).
